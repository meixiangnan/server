================================================================
  游戏服务器部署指南（基于腾讯云轻量服务器 + Drogon + Nginx）
================================================================
整理日期：2026-07-05

----------------------------------------------------------------
一、前置环境
----------------------------------------------------------------
- 服务器系统：Windows Server（腾讯云轻量服务器）
- Web 框架：Drogon（Game.exe）
- 反向代理：Nginx（负责 SSL 终止）
- 缓存数据库：Redis
- 客户端：Unity

----------------------------------------------------------------
二、部署新服务器实例的完整步骤
----------------------------------------------------------------

【步骤 1】复制旧服目录到新目录
  在本地 cmd 执行：
  xcopy E:\Project\server\exe E:\Project\server2\exe /E /I /H

【步骤 2】修改新服配置文件
  打开：server2\exe\config\game_config.json
  修改以下三处：

  1. listeners 端口（内部端口，不要和 nginx 监听端口冲突）：
     "port": 18443

  2. Redis db（与旧服隔离，避免数据混用）：
     "db": 1

  3. 日志路径（与旧服区分）：
     "log_path": "../logs2"

  注意：https 保持 false，SSL 由 Nginx 统一处理。

【步骤 3】创建日志目录
  mkdir C:\Project\server2\exe\logs2

【步骤 4】将文件上传到云服务器
  通过远程桌面（mstsc）映射本地磁盘，
  将 server2\exe 文件夹复制到云服务器对应目录。

【步骤 5】在腾讯云防火墙开放端口
  路径：控制台 → 轻量服务器 → 实例详情 → 防火墙 → 添加规则
  规则：协议 TCP，端口 8443，来源 0.0.0.0/0，策略允许

【步骤 6】启动 Game.exe
  cd C:\Project\server2\exe\bin
  start Game.exe

  验证是否监听成功：
  netstat -ano | findstr :18443
  看到 LISTENING 即正常。

【步骤 7】修改 Nginx 配置
  打开：C:\nginx\nginx-1.31.2\conf\nginx.conf
  在 http{} 块内，最后一个 server 块之后追加：

  server {
      listen       8443 ssl;
      server_name  bzhero.online;
      ssl_certificate      C:/nginx/nginx-1.31.2/certs/bzhero.online-chain.pem;
      ssl_certificate_key  C:/nginx/nginx-1.31.2/certs/bzhero.online-key.pem;
      ssl_protocols TLSv1.2;
      ssl_ciphers HIGH:!aNULL:!MD5;
      ssl_prefer_server_ciphers off;
      location / {
          proxy_pass http://127.0.0.1:18443;
          proxy_http_version 1.1;
          proxy_set_header Host $host;
          proxy_set_header X-Real-IP $remote_addr;
          proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
          proxy_set_header X-Forwarded-Proto https;
          proxy_connect_timeout 30s;
          proxy_send_timeout 30s;
          proxy_read_timeout 30s;
      }
  }

  保存后重载 nginx：
  cd C:\nginx\nginx-1.31.2
  nginx.exe -s reload

【步骤 8】修改 Unity 客户端连接地址
  文件：Assets/Project Data/Game/Scripts/Message/ServerHelper.cs
  修改 ServerURL：
  public const string ServerURL = "https://bzhero.online:8443";

  重新运行或打包，测试登录接口是否连通。

----------------------------------------------------------------
三、端口规划说明
----------------------------------------------------------------
  旧服（server）  ：Game.exe 内部监听 33055，Nginx 443 → 33055
  新服（server2） ：Game.exe 内部监听 18443，Nginx 8443 → 18443
  Redis           ：旧服用 db=0，新服用 db=1

  原则：Game.exe 只监听内部端口，外部访问统一走 Nginx SSL 反代。
  Nginx 监听端口和 Game.exe 内部端口必须不同，否则冲突。

----------------------------------------------------------------
四、常用排查命令
----------------------------------------------------------------
  # 查看所有监听端口及对应进程
  netstat -ano | findstr LISTENING

  # 确认某端口是否监听
  netstat -ano | findstr :18443

  # 查看 Game.exe 是否在运行
  tasklist | findstr Game

  # 强制关闭 Game.exe
  taskkill /IM Game.exe /F

  # 测试 nginx 配置文件语法
  cd C:\nginx\nginx-1.31.2
  nginx.exe -t

  # 重载 nginx（不中断连接）
  nginx.exe -s reload
